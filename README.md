# MVP Sprint – Interactive Card Template 

##Project Brief

This is an individual submission for Sprint 3. The objective of this exercise is to design and construct a **reusable card component** for a future E-Learning web application. This MVP is not an entire website, but a specific UI template that represents my own design direction, styling, and interactive features.

Every card is a teaser for a course, and comprises an image, title, brief description, and call-to-action button. Diverse styles of animation (e.g., tilt, gradient overlay, parallax, bounce, and flip) have been utilized to display visual attractiveness and kinds of interaction. These cards are to be proceeded with in order to transform further into a responsive list of courses.

Every piece is built in terms of –HTML, CSS & JS-- and are responsiveness- and accessibility-aware.

## Hypothesis

I believe that creating visually engaging and interactive course cards will increase user engagement by making it more intuitive and dynamic to navigate through courses. All animation effects are intended to highlight the importance of the card and bring focus to the "Enroll Now" call-to-action.

By testing this card design, I intend to explore:
- Whether visual feedback (on hover/click) improves discoverability of options
- Whether users are okay with using a non-static UI
- How style consistency contributes to overall usability
